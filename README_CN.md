这是一款 ComfyUI 自定义节点插件，为你的工作流提供全方位的节点整理能力。无需手动拖拽对齐，选中节点后一键完成对齐、尺寸统一、流式排列和颜色管理——全部搭配精心打磨的动画界面。

---

### 安装

进入 ComfyUI 的 `custom_nodes` 目录，克隆本仓库：

```bash
cd ComfyUI/custom_nodes/
git clone https://github.com/3ALLBUY14/ComfyUI-Majordomo.git
```

重启 ComfyUI 即可使用。画布中会出现浮动按钮，鼠标移到按钮上时会激活快捷弹窗，右键可激活快捷对齐整理弹窗，选中 1~2 个或更多节点后即可使用各项对齐和整理功能。

---

### 浮动按钮

ComfyUI 画布右下角的圆形浮动按钮是插件入口，支持以下交互：

| 操作 | 行为 |
|---|---|
| 左键单击 | 打开主面板 |
| 右键单击 | 切换对齐弹窗显示/隐藏 |
| 拖拽（左键按住移动 >4px） | 自由拖动按钮到任意位置，拖拽中自动隐藏所有弹窗与提示 |
| 悬停（>350ms） | 显示操作提示气泡（左键打开 / 右键对齐工具） |
| 悬停（>200ms） | 显示快捷颜色弹窗（悬停色块实时预览，点击生效） |

- 按钮位置自动保存到 localStorage，下次启动恢复
- 窗口缩放时自动夹紧到可视区域内

### 主面板

<div align="center">
<img src="https://raw.githubusercontent.com/3ALLBUY14/ComfyUI-Majordomo/main/doc/panel-cn.png" alt="面板总览" width="400">
</div>

<br>

主面板包含标题栏、对齐工具区、调色板区、自定义颜色区、透明度控制五部分。

#### 标题栏
- 显示插件图标 + 标题
- 可拖拽移动整个面板（位置自动持久化）
- 右侧 🧹 清理显存/内存按钮（一键释放 VRAM/RAM，含清扫动画 + Toast 反馈）
- 右侧语言切换按钮（中 / EN 互切）

#### 对齐工具区（14 种模式）

每个对齐按钮悬停时，画布上会显示蓝色虚线预览框，所见即所得。

| 类别 | 功能 | 说明 | 节点要求 |
|------|------|------|---|
| 边缘对齐 | 左 / 右 / 上 / 下 | 以选中最外侧节点为基准对齐 | ≥2 |
| 居中对齐 | 水平居中 / 垂直居中 | 所有节点中心点对齐到同一条线 | ≥2 |
| 尺寸统一 | 宽度最大 / 宽度最小 | 统一所有节点宽度为最大/最小值 | ≥2 |
| 尺寸统一 | 高度最大 / 高度最小 | 统一所有节点高度为最大/最小值 | ≥2 |
| 尺寸统一 | 尺寸最大 / 尺寸最小 | 整体尺寸统一为最大/最小 | ≥2 / ≥1 |
| 流式排列 | 水平流 (H-Flow) | 按选中顺序从左到右自动排列，间距可调 | ≥2 |
| 流式排列 | 垂直流 (V-Flow) | 按选中顺序从上到下自动排列，间距可调 | ≥2 |

**间距输入框**：位于对齐工具区下方，数值范围 0-200，默认 30，用于流式排列的间距，自动持久化。

**吸附间距输入框**：间距输入框右侧，数值范围 4-16，默认 8 — 控制拖拽吸附的灵敏度。仅在吸附功能开启时生效。

**撤销/重做按钮**：间距输入框右侧的 ↶ 和 ↷ 按钮，可撤销/重做上一次对齐或尺寸操作。使用独立的撤销栈，不影响 ComfyUI 原生撤销（颜色操作仍走原生撤销）。

#### 调色板区
- 内置 **14 套预设调色板**，每套 25 色在 5×5 网格中，专业配色方案（5 个色系 × 5 个明度等级），针对深色背景优化：原版暖色、原版混合、原版暗色、原版梦幻、标准彩虹、莫兰迪柔和、糖果亮色、深夜暗色、暖调复古、冷调科技、极简单色、森林自然、赛博霓虹、油画复古
- **自定义调色板**：将已保存的颜色存为自定义调色板并可命名（💾 按钮），存储在本地，显示在下拉菜单中；可用 🗑️ 按钮删除自定义调色板
- 调色板名称支持**下拉菜单**快速选择（点击名称展开全部色系）
- 箭头切换 + 索引显示（如 `3/10`）
- 圆点导航可点击直接跳转
- 调色板名称支持中英双语

#### 自定义颜色区
- **Hex 输入框**：手动输入 `#RRGGBB`，按 Enter 保存
- **拾色器**：内联颜色选择器，实时预览
- **工具栏按钮**（预览下方的独立行）：
  - 💧 **从节点取色**：读取第一个选中节点的颜色，加载到自定义颜色区
  - 🧪 **屏幕取色滴管**：使用浏览器原生 EyeDropper API 拾取屏幕上任意位置的颜色（不支持的浏览器自动隐藏）
  - 📋 **复制**：复制当前节点的完整配色方案（标题色、正文色、分组色、文字色）
  - 📥 **粘贴**：将复制的配色方案应用到选中节点/组（剪贴板有内容时显示颜色指示器）
  - 🗂️ **创建分组**：创建原生 LGraphGroup，带实时颜色预览圆点 — 自动应用当前颜色
  - 💾 **保存**：将当前颜色加入"已保存颜色"列表（最多 25 个，保存时按钮闪烁动画）
- **↶↷ 撤销/重做颜色按钮**：位于调色板圆点导航区右侧，撤销或重做颜色应用操作（最多 50 步）
- **已保存颜色条**：展示用户保存的颜色（最多 25 个），配 ◀▶ 分页导航（每页 9 格），点击应用
- **最近使用颜色条**：展示最近用过的颜色（最多 9 个），点击应用

#### 透明度控制
- 滑块范围 20% - 100%，默认 85%
- 实时调节面板透明度
- 数值自动持久化

#### 面板交互
- **平滑开关动画**：面板以 0.25s cubic-bezier 缩放过渡动画打开/关闭
- **双击空白处关闭面板**：在非按钮/输入框/颜色 chip 等功能区双击即可关闭
- **双击关闭提示**：鼠标在顶部标题栏区域停留 500ms 后显示"双击空白处关闭"提示，跟随光标
- **节点选中状态联动**：选中 >1 个节点时面板 handle 区域会高亮

### 快捷颜色弹窗

悬停浮动按钮 200ms 后弹出的小颜色面板：
- 3×3 网格布局：8 个最近颜色 + 中间 1 个随机配色按钮（🎲）
- **双色预览**：每个色块显示双色渐变（上方 38% 标题色，下方 62% 正文色）— 一眼看清两种颜色
- 网格下方**操作栏**包含三个纯图标按钮：
  - 💧 **取色**：读取第一个选中节点或组的颜色
  - 📋 **复制**：复制当前节点的完整配色方案 — 剪贴板有内容时按钮显示颜色指示器
  - 📥 **粘贴**：将复制的配色方案应用到选中节点/组
- 智能定位：根据屏幕空间决定显示在按钮左侧或右侧
- **悬停色块实时预览**：鼠标悬停色块时节点实时预览配色效果，移开自动还原
- 点击颜色永久应用到当前选中节点
- **🎲 随机配色按钮**：点击中间骰子按钮随机生成颜色并应用，弹窗立即刷新显示新颜色

### 对齐弹窗（右键浮动按钮）

与主面板的对齐工具区完全一致，底部额外增加**创建分组**按钮和**组标题字体滑动条**。

| 触发 | 行为 |
|---|---|
| 鼠标悬停按钮 | 画布上叠加蓝色虚线框预览对齐效果 |
| 点击按钮 | 执行对齐，弹窗保持打开方便连续操作 |
| 点击弹窗外部 / 按 Escape / 鼠标移出弹窗 | 关闭弹窗 |
| 开始拖拽浮动按钮 / 打开主面板 | 立即关闭弹窗 |

**创建分组按钮**：将所有选中节点包裹到原生 LGraphGroup 中，内边距正确（组标题栏位于节点上方，不遮挡）。显示实时颜色预览圆点。如果之前有取色（💧）或复制色（📋），会自动应用到组和组内所有节点。

**组标题字体滑动条**：弹窗底部，创建分组按钮下方。拖动滑条或输入数值（10–300px），实时调整组标题字体大小。

按钮的启用/禁用状态会随画布节点选择实时更新。

### 其他特性

#### 双栈撤销系统
插件使用**三套独立的撤销栈**，互不冲突：
- **对齐与尺寸撤销**（自定义栈）：处理对齐、尺寸统一、流式排列的位置和尺寸变更。最多 50 步。通过间距输入框旁的 ↶ / ↷ 按钮或面板打开时的 `Ctrl/Cmd+Z` / `Ctrl/Cmd+Y` 操作。
- **颜色撤销**（自定义栈）：处理调色板色块、快捷弹窗、自定义颜色的颜色应用。最多 50 步。通过自定义颜色区的 ↶ / ↷ 按钮操作。
- **ComfyUI 原生撤销**：其他操作的兜底。

面板打开且有对齐操作可撤销时，`Ctrl/Cmd+Z` 由面板拦截；否则透传给 ComfyUI 原生撤销。输入框中编辑文本时永远不会被拦截。

#### 自动配色
为节点配色时，保留用户选中的颜色作为背景，自动计算标题栏颜色和分组颜色。**标题文字**根据标题栏亮度自动切换为纯白或纯黑。**接口标签文字**默认保持纯白，仅在节点背景接近白色时（亮度 ≥ 0.85）才切换为黑色，确保任何配色下文字都清晰可读。

#### 双轨配色模式
自定义颜色区支持标题色（T）和正文色（B）独立编辑：
- **🔗 联动按钮**：在联动模式（标题色自动从正文色派生）和独立模式之间切换
- **T / B 按钮**：独立模式下选择当前编辑的颜色轨道
- **SV + 色相拾色器**：点击颜色预览打开内联饱和度/明度 + 色相拾色器，精确选色

#### 拖拽吸附对齐
开启后（Alt+S 或工具栏按钮），拖拽节点或组时自动吸附到附近元素的边缘和中心，并绘制蓝色引导线：
- 吸附到其他节点和组的左、右、上、下边缘和中心
- **粘性吸附**：距离在 1.5 倍吸附范围内的目标获得额外容差，自然对齐
- **Shift 旁路**：拖拽时按住 Shift 临时关闭吸附
- **UI 交互自动旁路**：指针位于任何面板 UI 元素（面板、浮动按钮、弹窗）上时自动关闭吸附 — 不冲突
- 吸附距离可配置（4–16 屏幕像素），在面板对齐工具区调整
- 关闭时零开销（仅一次布尔读取）

#### 快速打组
创建原生 LGraphGroup 包裹所有选中节点，内边距正确：
- 从对齐弹窗的「创建分组」按钮访问
- 使用原生 `resizeTo()` 计算边界 — 组标题栏位于节点标题上方，不遮挡
- 自动应用上次取色（💧）或复制色（📋）到组和组内所有节点
- 完全兼容 ComfyUI 原生组的编辑、调整大小和属性设置

#### 组标题字体修复（v20.3+）
从 ComfyUI 前端 v20.3 开始，原生 `LGraphGroup.draw()` 方法使用硬编码常量（`GROUP_TEXT_SIZE=20`、`NODE_TITLE_HEIGHT=30`）而非 `this.font_size`，导致右键菜单的「Font size」选项无效。插件通过 patch `LGraphGroup` 恢复 v20.3 之前的行为：
- **draw()** 使用 `this.font_size` 控制标题文字大小和标题栏高度（`font_size * 1.4`）
- **titleHeight** getter 返回 `font_size * 1.4`（按比例缩放，不再固定为 30）
- **configure()** 从工作流序列化数据中恢复 `font_size`
- **serialize()** 将 `font_size` 保存到工作流数据
- 在旧版内核（v20.3 之前）上该 patch 为透明无操作

#### Toast 通知
右上角滑入式通知，3 秒后自动消失，覆盖操作成功/失败、节点不足等场景。

#### 无障碍支持
所有按钮均设置 `aria-label`，对齐按钮支持键盘 focus 触发画布预览。
